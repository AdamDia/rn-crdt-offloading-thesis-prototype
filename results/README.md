## Results Folder

Store exported benchmark artifacts and summarized thesis data here.

Recommended contents:
- exported `benchmark-results.csv` files
- cleaned analysis CSV files
- tables prepared for the thesis write-up
- notes describing which simulator/device setup produced each dataset

Guidance:
- Do not commit oversized generated artifacts unless they are intentionally part of the thesis record.
- Keep raw exports and cleaned analysis files clearly separated by filename.
